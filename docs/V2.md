# Version 2: The Mini Assistant

v1 was a story-teller that only knew children's stories. v2 is a **mini general
assistant**. It learns from educational web pages, Wikipedia and stories, then
learns to hold real multi-turn conversations. It still runs offline on your phone.

v1 keeps working exactly as before. Every script takes `--version v2` for the new model.

## What's different

| | v1 | v2 |
|---|---|---|
| Brain size | 29.5M parameters | 88M |
| Memory (context) | 512 tokens | 1,024 tokens |
| Vocabulary | 8,192 | 16,384 |
| Reading material | 467M tokens of kids' stories | ~2.6B tokens: 80% FineWeb-Edu, 15% Wikipedia, 5% TinyStories |
| Chat training | 5k single messages | ~105k multi-turn conversations (smol-smoltalk + stories + identity) |
| Attention | Standard | Grouped-query (4 key/value heads for 12 query heads): smaller and faster on phones |
| Chat memory | Forgets after each message | Remembers the conversation (oldest turns dropped when full) |
| Training | ~4 hours | ~1–1.5 days, **pausable** |
| Phone file (Q8_0) | 32 MB | ~94 MB |
| Disk space needed | ~5 GB | ~10–15 GB |

## New tools in the code

- **`config.py`** holds every version's settings in one place. v1 and v2 live side by side.
- **Pause and resume.** Press **Ctrl+C** during `train.py` and it saves and stops. Run the same
  command again to continue. It also saves automatically every ~15 minutes, so a crash, restart or
  power cut costs at most a few minutes of work.
- **Resumable data prep.** `prepare_data_v2.py` saves progress after every batch. If it stops, just
  run it again.
- **KV cache** makes replies faster, because the model no longer re-reads the whole conversation
  for every new word.
- **`chat.py`** defines the chat format in one place, used identically for training, PC chat and
  the phone.
- **`evaluate.py`** is a 20-question test sheet (facts, explanations, advice, writing, stories). It
  scores a model so you can compare versions.

## Step by step

Run everything in your project folder with the virtual environment on:
```powershell
cd ~\Projects\a.i-sml
.venv\Scripts\activate
git pull
```

### Step 0: Before a long run
- Settings → System → Power: **Sleep = Never** (the screen turning off is fine).
- Settings → Windows Update → **Pause updates** for 1–2 weeks.
- Check you have **15 GB free**.

### Step 1: Quick test of the data download (~10 minutes)
```powershell
python prepare_data_v2.py --test
```
This builds a small 20M-token dataset in `data\v2-test` to confirm the downloads work. It should
end with `all done!`. If it errors, send a screenshot before doing the real run. You can delete
`data\v2-test` afterwards.

### Step 2: The real data (several hours, run it overnight)
```powershell
python prepare_data_v2.py
```
It trains the tokenizer (a few minutes), then encodes fineweb → wikipedia → tinystories, printing
progress and the hours left. **If it stops for any reason, run the same command again.** It
continues where it left off.

It's done when you see `wrote data/v2/train.bin: ~2,800,000,000 tokens` and `all done!`.

### Step 3: Pretraining (~1–1.5 days)
```powershell
python train.py --version v2
```
- Expect about **4–6 seconds per iteration** on an RTX 4070, for 20,000 iterations.
- **Ctrl+C pauses** it. `python train.py --version v2` resumes.
- Out of GPU memory? In `config.py`, set v2's `batch_size=4` and `grad_accum=32`.
- If memory use is low (check `nvidia-smi`), you can try `batch_size=16, grad_accum=8`, which is faster.

What the loss means: v2's numbers are **not comparable to v1's** (a different tokenizer and much
harder text). Web text is harder to predict than kids' stories, so expect v2's final val loss
somewhere around **2.5–3.0**. That's normal and good for this data. What matters is that it keeps
going down, and that train and val stay close.

You can peek while it trains (in a second window):
```powershell
python generate.py --version v2 --prompt "The sun is"
```

### Step 4: Chat data + fine-tuning (~1–2 hours)

`finetune.py` starts from the **final** pretrained weights (`final.pt`, or `latest.pt` for runs
started before that existed), not `ckpt.pt`. Val scores are noisy (±0.05), so the "best val"
checkpoint can be an older, less-trained model. Use `--base checkpoints\dev\v2\ckpt.pt` to pick
one yourself.
```powershell
python make_chat_data_v2.py
python finetune.py --version v2
```
**Ctrl+C pauses** fine-tuning too (it saves `chat_latest.pt`); run the same command to continue. It also
autosaves every ~10 minutes and shows the time left. `--fresh` starts over.

Want to change its personality? Edit `IDENTITY` and `GREETING` in `make_chat_data_v2.py` before
running it. Your own examples go in `data\v2\my_examples.jsonl`.

### Step 5: Talk to it and score it
```powershell
python generate.py --version v2 --chat
python evaluate.py --version v2
```
In chat, it remembers the conversation. Type `reset` to start over and `quit` to exit.

**Repetition penalty:** both scripts discourage repeating recent words (default
`--repetition_penalty 1.15`). If it still loops ("the cell wall and the cell wall…"), try `1.3`.
Use `1.0` to turn it off. Much higher (1.5+) makes it avoid normal words like "the".
`evaluate.py` prints a score out of 20 and saves every answer to `checkpoints\dev\v2\eval_chat.md`.
For comparison, v1 scores only its identity and story questions.

### Step 6: Put it on your phone
```powershell
python export_hf.py --version v2
python to_gguf.py --llama_cpp ..\llama.cpp --version v2
& "$HOME\Downloads\llama-b11192-bin-win-cpu-x64\llama-quantize.exe" export\dev\v2\my-ai-f16.gguf export\dev\v2\my-ai-q8_0.gguf Q8_0
```
Copy `export\dev\v2\my-ai-q8_0.gguf` (~94 MB) to your phone. In PocketPal, set **Context Size = 1024**
and, in the model's settings, **Repeat penalty ≈ 1.15** (the same idea as on the PC).
Multi-turn chat works this time, so no need to start a new chat for every question.

## Honest expectations

**v2 should:**
- Answer simple general questions ("What is photosynthesis?")
- Explain things in plain language
- Hold a short back-and-forth conversation
- Still tell stories

**v2 will still:**
- Get facts wrong fairly often, and sound confident when it does. Double-check anything important.
- Struggle with math, coding and multi-step reasoning. Those need much bigger models.
- Not know anything recent

## About the data

- **FineWeb-Edu** (`HuggingFaceFW/fineweb-edu`, `sample-10BT`): web pages filtered for educational
  quality.
- **Wikipedia** (`wikimedia/wikipedia`, `20231101.en`): the English encyclopedia.
- **TinyStories** (`roneneldan/TinyStories`): the v1 stories, so it keeps that skill.
- **smol-smoltalk** (`HuggingFaceTB/smol-smoltalk`): conversations built for small models. These
  were written by other AIs. Your model's brain is still trained 100% by you from random numbers,
  but its chat *style* is partly learned from them.

All are public datasets (text), not pretrained models.
