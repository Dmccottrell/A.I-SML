What it does

Private by default

The model is a file on your device, and Wikipedia is looked up there too. No tracking. For recent things like news or prices it can search the web, and when it does, the answer says so. You can turn that off, and private chats never search.

Remembers you, on your terms

It can save facts like your name, and you can edit or delete anything it remembers. Private chats are never stored.

Looks things up, and says so

It answers from what it knows first, and looks things up when it needs to: Wikipedia, the web for recent things, and live sources for prices, rates and scores. When it does, the answer says where it came from.

Exact where numbers matter

Sums, percentages, dates, time zones, exchange rates, loan payments and more come from code and free public sources, not from the model’s memory, so they are right.

Skills and Teacher mode

Study helper, Writing coach and more. Teachers make worksheets with answer keys, lesson plans, rubrics and parent emails, check class results with exact calculators, and save it all as PDF, Word or Google Docs. Students get guided help, quizzes and study plans.

Reads your documents

Add a PDF, Word or text file and ask questions about it, or have it summarised. The file stays on the computer that runs Emvryx.

VryxCode, a coding assistant

Builds and fixes projects, runs the tests in a safe sandbox, shows a live preview and explains what it did. Runs on Equinox, Solstice and Apogee.

Live preview

A web page you build appears beside the chat and reloads after every change. If the page has errors, one tap sends them back to be fixed.

Plan first, then build

Ask for a plan and it only looks around. You read it, change it, and press Build it when you like it.

Rewind any step

A snapshot is saved before each of your messages. Not happy with a change? Put the project back as it was.

Safe by default

It asks before it edits or runs anything risky. Sessions can run in an isolated sandbox with no internet, and it never sees your tokens.

See how it answers

Tap a question. These are examples we wrote to show the style (sources shown, “I don’t know” when it should say it), not live replies. Real answers come from the models and can be wrong: check anything important.

Who won the 2041 World Cup?
I don’t know. That is after what I was trained on, and I can’t see the future. If you turn on web search I can look up recent results and tell you where they came from.
It says so instead of making something up.
What is on my calendar tomorrow?
Looked in your Calendar. Tomorrow you have the dentist at 1:00 pm (Main St) and nothing else.
With a calendar connected, it reads only the few items that match, read-only, and says which app it looked in.
Why is the sky blue?
Sunlight is made of many colours. Air scatters the short blue wavelengths far more than the long red ones, so blue light reaches your eyes from every direction.
Source: Wikipedia, Rayleigh scattering
Facts come with the source they came from.
Make me a website for my dog walking business
Suggested language: HTML, CSS and JavaScript, because it needs no build step, so you can see it live in the Preview tab. I’ll start with a one-page site and show you before adding more.
VryxCode picks the best language for the job and says why; you can ask for another.
I couldn’t read my photo. What does it say?
I couldn’t read that picture: no words came out of it. Could you type the part you mean? I don’t want to guess what it says.
When it can’t read something it says so, instead of answering around it.
