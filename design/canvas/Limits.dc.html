When someone reaches a limit
Warn at 80%. At 100% pause that model and offer: use a smaller model, use the on-device model (no limit), or wait for the reset.
What is counted
Points = tokens x the model’s cost weight, so a bigger model uses more. Only numbers are stored, never message text. Resets: session every 5 hours, weekly Sun 2:00 AM.
